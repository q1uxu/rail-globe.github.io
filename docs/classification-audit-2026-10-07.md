# 铁路设计时速与区段核查，2026-10-07

已将地图改为七档设计时速，并按区段分别着色。长线路保留一个身份，整条选择和高亮，图层关闭只隐藏对应等级区段。设计时速、轨道设计标准和参考运行速度分开保存，设计值不会用于提高寻路的估算运行速度。

## 数据及覆盖范围

参考 [中国动车组线路资料](https://www.china-emu.cn/RailRoads/HSR/)。HSR 入口本身是图像地图，本项目没有复制其图像。实际读取该站干线、区域、城际目录的 297 条线路页面，共 704 个区段记录，并保存区段别名、起终点、三种速度字段、来源链接和读取日期。另保存了 910 条开工、开通等日期参考记录，以及线路数、供电、轨距和列控事实字段。日期记录中的计划措辞有单独标记，参考日期不自动改变地图建设状态。

213 个地图线名匹配到参考记录，其中 172 个名称有明确定位并应用的设计区段，共 253 个匹配范围。相邻且同一设计值的参考区段会合并为一个应用范围，数量不等于原网站卡片数。当前线路列表有 39 条线路包含多个已匹配等级。

资料保存在 `data/rail_design_catalog.json`，经注释核实的小范围记录保存在 `data/rail_design_overrides.json`，边界使用同一 OSM 快照提取的车站、线路所和信号点坐标，见 `data/rail_design_points.json`。完整覆盖率、匹配范围和待核查原因见 `output/design/coverage.json`。覆盖率使用显示路径的坐标长度计算，只用于匹配检查，不是营业里程统计。

## 分级与资料使用规则

| 图例 | 具体值示例 | 使用方法 |
| --- | --- | --- |
| >350 | 380、400 | 保留具体线下设计值，不代表列车以此运行 |
| 350 | 350 | 350 档 |
| 300 | 300 | 300 档 |
| 250 | 250 | 250 档 |
| 200 | 200、205 | 200 档，保留原始数值 |
| 160 | 160、165 | 160 档，保留原始数值 |
| <160 | 80、100、120、130、140 | 低于 160 的明确设计标准 |
| 中性色 | 未知 | 辅助状态，不是第八档设计速度 |

优先采用线下设计值，缺失时采用明确的轨道设计值。OSM 的 `maxspeed` 不作为设计时速。站内运行限速也不会把整条铁路反复切成低等级。

必须读区段注释，包括用不同颜色显示的停运或建设提示。有 25 个卡片的设计范围或定义需要复核，不能直接用标题最高速度覆盖整段。比如京哈长春北至哈尔滨西卡片的 200 只明确指向兰棱至五家。该小范围按 200 标注，其余范围保留已有明确依据或待核实。成贵眉山东至乐山的标题设计值也不能忽略青神至乐山的不同线下标准。

## 连续性与验证

先用原有轨道去重、接续和顺滑程序建立整条几何，再在车站或线路所投影位置切分颜色，两侧共享同一个切点，不移动轨道。匹配只沿该物理线路的路径展开，不用城市矩形范围整块涂色。不同设计值相互冲突、边界缺失、路径无法接续时保留待核实。

已修复重算时浮点投影把精确接头变成极短边、导致区段匹配失败的问题，并加入多次切分后仍能连通的测试。46 项测试通过，涵盖七档边界、运行与设计值分离、页面注释限制、重复切分、范围冲突和几何接头。

浏览器验证：七档和未知层开关正常，杭深的 200、250、350 与未知区段一起高亮，关闭 200 时其高亮同步隐藏。手机界面没有水平溢出。香港南昌、奥运的并排线现场截图保存在 `output/design/`，本轮速度切分没有重画这些地铁几何。

全国几何检查按同一线路合并不同颜色，新增了跨分段连接点的急转检查。地铁、市郊和国铁共线叠加层的自动重复、断开、急转检查均为 0，地铁遮挡及孤立偏移也为 0。铁路原有断线和重复候选仍保留。合并接头后新增检出 12 个急转候选，包含道岔、轨道接头或显示折返的可能情况，尚未逐项认定，不能据此声称全国线路都无问题。完整候选坐标在 `output/design/layers-final.json`。

源快照更新、建设状态修正和官方资料见 [全国数据核查](rail-data-audit-2026-10-07.md)。本地预览 http://localhost:8765/ ，尚未提交或推送。

## 后续更新（2026-10-07 晚）

本节取代上文中“设计值无法确认时用中性色并注明待核实”的口径和相应数字。

- 图例不再设“待核实”。没有设计时速资料的线路列为“普速铁路”。例外是高铁和快速铁路：轨道限速已把它归入 350、250、200 档的线路，缺资料的区段暂按该档画，属性标 `e`，卡片注明“按轨道限速归档，设计时速待核实”。
- 参考资料补读了“联络线及枢纽内线路”目录，资料从 297 页、704 个区段增到 643 页、1068 个区段。
- 匹配补充：卡片没有轨道名时用卡片标题对线名；高速、客专、城际视为同一类叫法；一条高铁的全部卡片给出同一个值时整条采用；区段终点在线路端头之外时取到端头；上下行分开走的另一股道沿用它离开并回到的区段；被隧道名切断的线路（台湾高铁）接回原线。
- 读源页注释和线上来源后写入 `data/rail_design_overrides.json` 的范围共 48 条，每条带出处和依据。线上来源包括生态环境部环评批复（安庆联络线、西十高铁）、国家铁路局项目简介（哈齐）、重庆市发改委（渝利）、新华社和人民日报（汕汕、昌九），其余为维基百科和百度百科，依据里已注明。
- 结果（按图上长度）：有设计时速资料 77215 公里；高铁里仍按轨道限速暂归档 1118 公里，共 141 段，其中 107 段不足 10 公里；普速 123726 公里。清单在 `output/design/coverage.json` 的 `to_verify`。
- 查过但没有写入的：广深线仙村至石龙以外（只有整线或运行速度）、武孝城际孝感东至云梦东（250 与 350 两种说法冲突）、京港高铁肥西段（环评 160 与批复 350 冲突）、合宁联络线（160，只有转载）、唐山北联络线（200，只有百科且未能复核）、庄桥至宁波（120 只指新增三四线），以及各枢纽进站段（来源只有运行速度或没有数值）。
